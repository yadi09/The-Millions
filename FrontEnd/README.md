# Frontend — The Millions

Quick setup for local development (frontend).

Prerequisites
- Node.js 16+ (or compatible LTS)
- pnpm (install with `npm i -g pnpm`)

Setup
```bash
# from repo root (after cloning)
cd FrontEnd
pnpm install
pnpm dev
```

Build
```bash
pnpm build
pnpm preview
```

Notes
- If you see dependency or Node errors, ensure your Node version matches the prerequisite.
- For repository-wide CI or deployment instructions, see the root README.
